# Brand assets — The Jewish Board logo

The app looks for these files (first one found wins) and falls back to the text name
"The Jewish Board" when none exist:

| File | Used for |
|---|---|
| `jewish-board-logo.webp` / `.svg` / `.png` | Header and sign-in card (light backgrounds). Current file: Primary RGB web lock-up, 658×300, transparent. |
| `jewish-board-logo-white.webp` / `.svg` / `.png` | Dark backgrounds (reserved) |
| `favicon.svg` / `favicon.png` (The Radiant symbol only) | Browser tab icon |

Get the official files from The Jewish Board's brand/marketing team (preferred — the brand kit
has RGB/white lock-ups), or save the header logo from https://jewishboard.org/ in your browser.
EPS files from the brand kit must be exported to SVG or PNG first. Don't redraw, recolor,
stretch or crop the logo.
