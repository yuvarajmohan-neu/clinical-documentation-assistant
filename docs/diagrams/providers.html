Rules for every wrapper

Real = built and tested. Minimal = interface plus one simple adapter. Describe only = documented, not built.
Adapters return our types (Passage, Principal, Issue), never SDK objects. No vendor import outside providers/.

Proven before switching

Contract tests in tests/providers/ run the same suite on every adapter. The evaluation matrix must not change after a switch.

Runs locally

Native Postgres + pgvector, AUTH_PROVIDER=dev for sign-in (Keycloak optional, if time allows), backend, frontend — no container runtime required. All Apache-2.0 / MIT / PostgreSQL licensed.
